# Examples

Made-up sites for trying the app. None of them is a real project.

| Project | What it shows |
|---|---|
| `factory-two-roofs.spvd` | 841 panels on two trapezoidal roofs with walkways and skylights, 4 × SolaX X3-FTH-100K |
| `office-flat-roof.spvd` | Concrete flat roof with a plant room, imported from Excel, dry zone |
| `warehouse-dxf.spvd` | Standing seam roof imported from an AutoCAD DXF (panel blocks), mid country |
| `school-hill-country.spvd` | Amano roof from a DXF of plain rectangles, hill country temperatures |
| `house-google-earth.spvd` | Clay tile house roof from Google Earth measurements, single-phase inverter; 3 panels are left unconnected, so the Checks tab shows a warning |
| `large-shed.spvd` | 1.3 MWp shed with run breaks and walkways, 8 × X3-FTH-125K |
| `mixed-inverters.spvd` | Three 125 kW and one 60 kW inverter that are too small for the array, so every inverter is below the overload window |

Open a project with **File > Open**. The `layouts` folder has the CSV, Excel and DXF files the roofs came from. Use them to try **Import CSV / Excel** and **Import AutoCAD DXF** yourself.
